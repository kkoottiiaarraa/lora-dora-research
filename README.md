# Исследование готовых LoRA / DoRA адаптеров

Цель — установить, какие свойства готовых DoRA-адаптеров связаны с различиями
качества относительно LoRA и насколько выводы из геометрии весов и вмешательств
устойчивы к эквивалентным представлениям одной функции. Используем уже обученные
публичные checkpoints; собственное обучение не проводилось. Преимущество DoRA
заранее не предполагается.

Научная цель — самостоятельный содержательный результат, потенциально для
конференции уровня B. На 14 октября 2026 такой результат **не получен**:
общий механизм преимущества DoRA и конкурентоспособный новый алгоритм сжатия
не установлены. Есть воспроизводимые ограниченные наблюдения, отрицательные
проверки гипотез и аудит публичного кода SORA.

**Статус: исследование приостановлено пользователем.** Передача репозитория
другому агенту не разрешает запуск старых очередей или новых экспериментов.
Состояние остановки зафиксировано 14 октября; это не текущая телеметрия сервера.

## Что уже сделано

- Полная оценка base / LoRA / DoRA на трёх парах Qwen3-4B: GSM8K (1 319),
  MMLU (14 042), SQuADv2 (11 873). Общего устойчивого преимущества DoRA не найдено.
  Три задачи одной архитектуры не заменяют независимые семейства и seeds.
- Радиальные вмешательства и локализации по Q/K/V/O; проверены парные изменения
  ответов, взаимодействия, чувствительность к scorer и множественным сравнениям.
- Численные проверки сохраняющей функцию V/O-симметрии. На Qwen подтверждена
  зависимость KL-рейтинга отдельных абляций от представления; подтверждающая
  проверка этого эффекта на Mistral не прошла. Сама симметрия известна.
- Проверены несколько способов сжатия и распределения ранга; нового метода
  с установленной пользой против сильных baselines не получено.
- Проверены гипотезы о magnitude, normalization, downstream компенсации
  и траектории PeRL. Они не дали нового практического тезиса.
- Найдены воспроизводимые ошибки export / unmerge / loading в зафиксированном
  публичном коде SORA. Это **не опровержение опубликованных таблиц качества**.

Подробности и условия пересмотра — в навигаторе и аудите. Рабочий ориентир
стоимости кампании — около 160 GPU-часов; это не полный аудированный total.
Отдельно учтены 130,998 часа inference основного пакета и 26,098 часа wall time
следующего, с разными областями учёта; их нельзя выдавать за точный общий расход.

Большие веса, datasets, logits и полные журналы вычислений не входят в Git.
Приватные сведения о доступе и размещении артефактов хранятся отдельно и исключены
из публикации. Клон достаточен для чтения отчётов и компактных данных,
но не для автоматического полного воспроизведения всех модельных прогонов.

Не запускать старые инструкции установки, пилоты и контроллеры по одному лишь
их наличию. После явного возобновления выбрать конкретный нерешённый вопрос,
проверить литературу и определить критерий остановки **до** вычислений.
Отрицательные исходы сохранять; не расширять сетку после провала ради сигнала.

[код авторов](https://github.com/NVlabs/DoRA), [сохранённый PDF](papers/2402.09353v6.pdf).
