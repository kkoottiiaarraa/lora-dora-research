# LoRA / DoRA research

Материалы для продолжения исследования причин различий между LoRA и DoRA.

- [Контекст обсуждения](LORA_DORA_RESEARCH_CONTEXT.md): цели, проверенные источники, математический аргумент и его ограничения, доступные материалы и обсуждавшиеся гипотезы.
- [Расширенный каталог готовых пар](CHECKPOINT_INVENTORY_2026-10-09.md): десять основных пар-кандидатов, дополнительные серии, проверенные весовые файлы и ограничения сопоставимости.
- [Предыдущий аудит открытых checkpoints](OPEN_CHECKPOINTS_AUDIT.md): Answer.AI, LLaVA и литература о механизмах.
- [Исходная статья DoRA, arXiv 2402.09353v6](papers/2402.09353v6.pdf): **DoRA: Weight-Decomposed Low-Rank Adaptation**, Shih-Yang Liu et al., ICML 2024; версия от 9 июля 2024 года.

Публичные источники статьи: [arXiv](https://arxiv.org/abs/2402.09353v6), [HTML](https://arxiv.org/html/2402.09353v6), [код авторов](https://github.com/NVlabs/DoRA).

Собственное обучение ещё не проводилось; подтверждённого нового объяснения преимущества DoRA пока нет. Файл контекста содержит сведения из предыдущего обсуждения, а не окончательный протокол эксперимента.

Подготовка: [протокол](docs/RESEARCH_PROTOCOL.md), [сетевой доступ](docs/REMOTE_ACCESS.md),
[зафиксированные revisions пилотной пары](configs/shadow_qwen3_4b_gsm8k.json).
Агент работает в облаке, GPU-скрипты — в отдельном новом checkout на сервере.
Лимит: максимум три GPU одновременно, первый прогон на одной свободной GPU.

Read-only диагностика сервера без установки библиотек:

```sh
python3 scripts/server_preflight.py --output results/preflight.json
```

CPU-проверки (нужен NumPy):

```sh
python3 -m unittest discover -s tests -v
```

На GPU-сервере, после проверки доступности GPU и установки библиотек в venv:

```sh
python3 scripts/download_pilot.py --plan-only
python3 scripts/download_pilot.py
python3 scripts/run_pilot.py --workers 1 --merge-check
```

Скрипты пилота ещё не проверены на GPU. Первый запуск проверяет восстановление,
время и память; восемь маленьких примеров не заменяют полноценную оценку качества.
Контекст продолжения после изменения облачной сети — [HANDOFF](docs/HANDOFF.md).

PDF принадлежит авторам статьи и включён как исследовательский материал; условия использования определяются лицензией оригинальной публикации.
