# LoRA / DoRA research

Материалы для продолжения исследования причин различий между LoRA и DoRA.

- [Контекст обсуждения](LORA_DORA_RESEARCH_CONTEXT.md): цели, проверенные источники, математический аргумент и его ограничения, доступные материалы и обсуждавшиеся гипотезы.
- [Исходная статья DoRA, arXiv 2402.09353v6](papers/2402.09353v6.pdf): **DoRA: Weight-Decomposed Low-Rank Adaptation**, Shih-Yang Liu et al., ICML 2024; версия от 9 июля 2024 года.

Публичные источники статьи: [arXiv](https://arxiv.org/abs/2402.09353v6), [HTML](https://arxiv.org/html/2402.09353v6), [код авторов](https://github.com/NVlabs/DoRA).

Собственное обучение ещё не проводилось; подтверждённого нового объяснения преимущества DoRA пока нет. Файл контекста содержит сведения из предыдущего обсуждения, а не окончательный протокол эксперимента.

PDF принадлежит авторам статьи и включён как исследовательский материал; условия использования определяются лицензией оригинальной публикации.
