# Исправление загрузчика до первых измерений

14 октября2026. Первая GPU попытка завершилась через16.51s на стадии setup,
до native outputs и любых сравнений. Ошибка: `Cannot copy out of meta tensor`.

В PEFT0.17.1 `load_adapter` при наличии hf_device_map использует `device_map=auto`,
если карта не передана явно. В CUDA-visible процессе это повторно распределило
CPU-loaded модель и оставило offloaded meta параметры. Проверка точной загрузки
правильно остановилась; её не ослабляли. Другие процессы не трогались.

Исправление: базовая модель загружается без device_map (полностью CPU), адаптер
с явными torch_device=cpu/device_map=cpu, затем параметры проверяются и только
transformer переносится на GPU. Никакие data/weights/условия/численные критерии
не изменены. Три tiny CPU tests прошли, включая save/reload той же функции;
они также выполняются с CUDA visible до реальных весов. Ни один параметр не
может оставаться meta, а неожиданные dispatch hooks запрещены.

Неудачная попытка/логи/старые source hashes сохранены приватно, отдельно от retry.
GPU процесс завершился, контекст освобождён. В суммарный расход включать эти
16.51s GPU-phase wall (~.00459GPUч); это не успешный inference результат.
