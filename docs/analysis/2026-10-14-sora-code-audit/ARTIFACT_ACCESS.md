## Прямой путь

Публичные научные контакты из [финального PDF, стр.1](https://ojs.aaai.org/index.php/AAAI/article/view/40267/44228):
первый автор Da Chang — changda24@mails.ucas.ac.cn;
corresponding author Yongxiang Liu — liuyx@pcl.ac.cn.
Первый контакт также указан на персональном сайте автора.

Минимальный запрос — **один** готовый SORA adapter из таблицы GLUE для
DeBERTaV3-Base, RTE либо MRPC. Для loader/rotation audit этого уже достаточно;
не обязательно сразу получать всю коллекцию. Запросить classifier/pooler heads,
base/tokenizer revision, config/seed, точный evaluation command/code revision,
versions и reference predictions/log. Для проверки относительного преимущества
дополнительно нужны согласованные LoRA/DoRA checkpoints и seeds.
Публичный release не обязателен: пригодна разрешённая авторами private ссылка.

База microsoft/deberta-v3-base проверена через HF API: gated=false,
revision `8ccc9b6f36199bec6961081d44eb72fb3f7353f3` на дату проверки.
Это текущая доступность базы, **не подтверждённая training revision автора**.
GLUE результаты в статье действительно относятся к DeBERTaV3-Base;
точное соответствие README/кода/запуска нужно запросить, не предполагать.

Письмо подготовлено локально, **не отправлено**. До отдельного указания
пользователя внешние сообщения не отправлять.

## Без авторских весов

Возможны полноценные проверки формул, гарантии norm preservation, export/load
semantics, границ entropy interpretation на наших готовых DoRA. Уже имеющиеся
tiny witnesses доказывают implementation errors независимо от training.
Расширение на реальную архитектуру может укрепить software/reproducibility
отчёт, но не доказывает порчу опубликованного benchmark.

Для качества можно независимо воспроизвести обучение небольшого ungated
DeBERTa/GLUE по авторскому рецепту. Авторские веса для такой репликации
логически не обязательны. Но это новое обучение: оно запрещено текущим
пользовательским условием и в этом этапе не запускается. Независимая репликация
проверяла бы опубликованный метод/рецепт; без исходных артефактов она не
установит, какой pipeline породил конкретные авторские числа.

Теоретический контрпример к опубликованному универсальному утверждению тоже
может быть значим без weights. Нужен именно такой точный тезис: ошибки записи
или иллюстрация уже известной gauge свободы не равны опровержению всей работы.
Новое обучение/исследование dataset не начинать ради самого продолжения ветки.

## Почему это пауза, а не исчерпание направления

Остановлены дальнейшие model comparisons без необходимой provenance и
training authorization; не доказана невозможность исследования. Следующий
конкретный шаг — запросить минимальный checkpoint и evaluation provenance.
Без ответа можно продолжить ограниченный формальный аудит либо отдельно
согласовать независимую малую репликацию. Из найденных bugs не следует ни
неработоспособность SORA как метода, ни гарантированная статья уровня B.
