# Короткая проверка: вывод V против O зависит от представления

14 октября2026. Восемь **старых калибровочных** вопросов, 256 gold-prefix
предсказаний/условие, common dense CPUFP32. Это screen, не подтверждающая
статистика, не accuracy и не объяснение обучающей траектории.

При неизменных W0/A/B/r magnitude V умножается на c, O — на1/c.
Исходная функция и совместное removeD-VO сохраняются алгебраически.
Отдельные removeD-V/O задают разные контрфактические вмешательства после
такого изменения представления; их реализация из-за этого не становится ошибочной.

| c | KL после removeD-V | KL после removeD-O | Большее расхождение |
|---:|---:|---:|---|
| .995 | .00005733 | .00002764 | V |
| 1 | .00001597 | .00001019 | V |
| 1.005 | .00003135 | .00004951 | O |

Размах контраста V−O=4.786e-5, 83.5% максимального raw KL. Frozen screen gate
смены ordering пройден. Знак gold-NLL эффектов отдельных raw абляций **не**
изменился, дополнительный NLL gate не пройден. Число изменившихся argmax крайне
мало; по этим данным нельзя утверждать смену рейтинга по точности задач.

Разделение D на геометрическое среднее и относительные масштабы строк
позволяет определить три вмешательства: убрать относительную V-форму,
O-форму или общий gain ветви. Их численная инвариантность при тех же c прошла
малые контроли. Это явный выбор estimand, не единственная истинная причинная
декомпозиция. Эффекты отдельных вмешательств не надо складывать без взаимодействий.

Три tiny GQA algebra tests PASS; native4case bitwisePASS; 80 строк приняты.
40 numeric controls: maxRMS1.250e-5 против min interventionRMS.01110,
то есть0.113% эффекта, ниже1%gate. Общий execution path не менялся между
raw/centered условиями. Работа190.70с CPU16, GPU0ч, worker завершён.
