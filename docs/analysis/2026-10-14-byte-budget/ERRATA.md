# Уточнение числа тензоров в спецификации

14 октября 2026, до завершения 128-case сравнения. В VALIDATION_SPEC.md
ошибочно написано «144 modules/480 source tensors»: у Qwen 144 модуля ×
(A, B, magnitude) = **432** исходных адаптерных тензора. Число 480 относится
к ранее проверенному Mistral с 160 модулями. Код проверяет реальные значения
всех тензоров через verify_loaded_adapter, не использует ошибочное число480.

Спецификация и запущенный код остаются побайтно неизменными для воспроизводимости.
Это исправление описания; условия, размер выборки и критерии не меняются.
