# Обнулённая K1 не объясняет основную потерю

Exploratory endpoint diagnostic,14октября2026. Все3×64условия завершены.
Возврат native K-проекции слоя1 устранил лишь4.13% excessKL у weighted allocation

«провал вызван главным образом единственным rank0» не поддержана этим тестом.

В каждом случае остальные143проекции неизменны. Native source и cached teacher

качества алгоритма. Bootstrap whole-question изменения приведены
в[restoration-validation.json](restoration-validation.json).

или единственной причины ошибки во всех возможных конфигурациях.
Расширять это в полный перебор восстановлений отдельных слоёв сейчас не нужно:
проверяется уже обоснованный full affine candidate с influence-aware objective.
