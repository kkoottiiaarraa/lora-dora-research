# Локальная необходимая граница для воспроизведения выхода головы

14 октября2026. Исследовательская постановка до вычисления screen. Не новый
общий принцип rank/SVD и не доказательство глобальной выразимости сети.

Пусть столбцы O0_h задают выходную проекцию одной фиксированной головы базы.
Q — ортонормированный базис её column space, P=I−QQᵀ. Любая LoRA-r изменяет
эту голову как O_L=O0_h+B A_h, rank(B A_h)<=r. Для любых входов Z_L,
в том числе полученных другими Q/K/V, её выходы Y_L=O_L Z_L удовлетворяют
`rank(P Y_L)<=r`, потому что P O0_h=0.

Для фиксированной таблицы target head outputs Y_D therefore
`||Y_D−Y_L||F² >= ||P(Y_D−Y_L)||F² >= sum_{j>r} sigma_j(P Y_D)²`.
Последняя граница — обычная best-rank-r approximation. Она необходима, не
достаточна для существования LoRA решения. Не требует одинакового Z_L и Z_D,
но относится к **совпадению одной обозначенной головы**: другие головы/слои
могут компенсировать ошибку. Это не lower bound на logits/accuracy всей сети.

У DoRA `O_D=D(O0+B A)`. Тогда P D O0 может иметь ранг выше r: диагональ
меняет output subspace головы, тогда как общий скалярный gain этого не делает.
Из числа новых направлений не следует их полезность или причина обучения.

Измеряем P Y_D на реальных сохранённых O-inputs X_h: Y_D=O_D,h X_hᵀ.
Число строк2048=64calibration cases×32gold-prefixpositions. Спектры считаются
FP64 через128×128covariance и thin products, без2560×2048SVD. Никакого ridge:
используем точную эмпирическую PSD covariance с обнулением только численно
отрицательных eigenvalues в пределах tolerance. Это точная finite-sample
матрица, не population lower bound. O_D для shadow arithmetic заново строится FP64 из исходного savedm/W0/A/B,
не из округлённого D. Численный пол оцениваем по разнице merged FP32 weight и FP64 формулы
на тех же head inputs; observed outputs не заменяются голыми weight norms.

V/O gauge меняет X_h→c X_h, O_D,h→O_D,h/c. Поэтому Y_D, P Y_D и их спектр
инвариантны. База O0_h и projector остаются теми же. Это иной объект, чем
неинвариантная энтропия отдельных W−W0. No-D control O0+B A должен давать
tail после r на уровне FP64 округления; никакой готовый LoRA checkpoint для
проверки этого алгебраического свойства не требуется.

## Ближайшая литература и отличие вопроса

- [LatentLLM §4.2](https://arxiv.org/html/2505.18413v1) уже использует совместные
  OV operators и в Remark11 сообщает ограничение простого joint loss. Общая
  совместная аппроксимация и произведение OV не новая идея.
- [A3 §§3.2, B.2](https://arxiv.org/html/2505.12942v1) уже приближает OV с учётом
  attention-conditioned активаций. Weighted SVD такого оператора уже известен.
- [Zeng & Lee, ICLR2024, §4/F](https://arxiv.org/html/2310.17513v3) изучают
  rank-based functionality gaps через составные матрицы Transformer. Их
  sufficient-expressivity результаты имеют свои архитектурные предпосылки;
  ими нельзя объявить новый глобальный lower bound для Qwen/GQA/RMSNorm.
- [Intruder Dimensions](https://arxiv.org/html/2410.21228v3) уже рассматривает
  новые спектральные направления относительно базы. Здесь natural head output
  column space фиксирован архитектурным размером головы, а target — actual
  head output table. Само обсуждение subspace novelty не новое.

Узкий вопрос: насколько велики в готовой DoRA **наблюдаемые** компоненты вне
этого локального necessary LoRA-r класса, если удалены phantom scale changes?
Если они малы, не стоит строить новый алгоритм или объяснять успех DoRA одним
формальным полным рангом. Если существенны, следующая проверка — контролируемое
функциональное вмешательство, а не новое сравнение голых ranks. Новизна этой
конкретной прикладной постановки пока не установлена; уровеньB не заявляется.
