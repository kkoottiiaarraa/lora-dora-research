# Mistral: KL-рейтинг не перевернулся, NLL-знак требует подтверждения

14 октября2026. Загрузка другой готовой архитектуры технически принята:
оба base shard SHA проверены, адаптер SHA совпал с pinned inventory,
480BF16тензоров точно загружены в FP32, все160targets/r32/alpha64/scaling2
верны. Gate_proj корректно загружен и не меняется при V/O вмешательствах.
Четыре native повтора побитны, все40численных контролей проходят.

8вопросов сопоставлены с Qwen fresh64, но токенизированы Mistral по plain
авторскому формату. Это256gold-prefix позиций/условие, не benchmark accuracy.

| c | KL V_off | KL O_off | Δgold NLL V_off | Δgold NLL O_off |
|---:|---:|---:|---:|---:|
| .995 | .00035644 | .00002286 | +.00067588 | −.00039602 |
| 1 | .00025888 | .00000679 | −.00013517 | +.00027795 |
| 1.005 | .00021607 | .00004672 | −.00089181 | +.00099886 |

**КЛ-результат Qwen на этом screen не повторился:** V меняет распределение
сильнее O при всех трёх c. Этот отрицательный факт сохраняем, не ищем другой c.
Но заранее предусмотренный альтернативный NLL screen gate пройден:
знаки средних эффектов каждой абляции меняются при фиксированных .995/1.005,
размах .001568/.001395 nat/token превышает заданный .001 порог.
Пока это восемь случаев и не статистическое подтверждение.

Центрированные вмешательства численно инвариантны к source gauge;
maxcontrolRMS2.981e-6 против minimumeffectRMS.007997, остаток0.0373%эффекта.
Веса/исходный случай после контекстных замен восстановлены;80строк конечны.
Wall494.86с CPU16, включая download11.21с и verification62.37с;
peakRSS43.06GiB, GPUне использовались, worker завершён.

Проверка мощности по этим8случаям очень приблизительна. Для NLL O_off при
.995 pilot SD=.001251 и mean=−.000396: нормальная оценка80%power при
four-test correction даёт около112вопросов. Для V_off .995 получается около260.
Поэтому не запускаем64вопроса с последующим добором после просмотра:
до новых outputs фиксируем **128новых вопросов**, без дальнейшего увеличения
n при неопределённом результате. Это ограниченный шанс подтвердить хотя бы
одну заранее заданную пару знаков, не гарантия мощности.

Валидация будет проверять4абсолютных NLL-эффекта против native source сHolm4,
а не менять primary metric по её результатам. Полный план:
[VALIDATION_SPEC.md](VALIDATION_SPEC.md). B-уровень/качество свободной генерации
не установлены; training recipe checkpoint остаётся неподтверждённой.
