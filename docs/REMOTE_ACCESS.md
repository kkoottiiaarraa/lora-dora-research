## Ограничение текущего облака

HTTP/HTTPS через inherited proxy и raw TCP через CONNECT — разные возможности.
Разрешённый Интернет не открывает автоматически SSH. Не менять локальную
network-policy.json, маршруты или TLS-проверку. Устанавливать новую VPN внутри
облачного контейнера не требуется. Проверка по паролю root невозможна до
доступного транспорта. Это историческая причина переноса CLI на VM; не начинать
новый цикл диагностики облачного TCP для продолжения исследования с VM.
