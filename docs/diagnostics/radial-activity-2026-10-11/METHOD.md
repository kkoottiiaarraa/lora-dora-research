# Radial activity measurement

This post-campaign CPU diagnostic measures GSM8K Qwen3-4B endpoint weights, not a training mechanism. Base tensors are native BF16 promoted to FP32; raw A/B/m remain FP32. Scaling is 32/32=1. Ideal quantities are L=BA, U=W0+L, n=rowNorm(U), g=m/n, WD=gU and Wreset=(rowNorm(W0)/n)U. R=(g-1)U and Rm=((m-rowNorm(W0))/n)U use stable equivalent formulas; explicit FP32 subtraction and row norm identities are checked with recorded tolerances.

R0=(g-1)W0 is the conditioning term; GL=gL. FP64 sums over FP32 blocks verify Delta energy=R0 energy+GL energy+2 dot(R0,GL). Norm ratios are square roots of global sums of squares, never means of module ratios. Global quantiles concatenate all row arrays. Delta=WD-W0; R energy/Delta energy can exceed one. Endpoint baseline residuals compare saved m with FP32 base row norms, BF16 casts of those norms, and CPU BF16 row norms. Training initializer/library/base provenance is unknown, so these are not learned movement.

Dense proxies cast WD, U and Wreset individually to actual torch BF16. Element differences, exact equal counts, fully equal rows and their cross-tabs with BF16(g)==1 are measured after promoting the rounded matrices to FP32. Dense Delta is BF16(WD)-W0 and dense L is BF16(U)-W0; these are the ratio references. This proxy is not PEFT function fidelity. BF16(g)==1 is a counterfactual quotient cast. Actual current-PEFT-operation CPU surrogate executes identity B(A(I)) under CPU BF16 autocast, adds its BF16 result to FP32 W0, computes FP32 norm and FP32 g. Installed PEFT get_weight_norm is checked on a toy; CPU kernels do not establish historical CUDA bitwise behavior. Surrogate R uses (g_surrogate-1)U_surrogate.

All used weight files are SHA256-verified before measurements against the pinned config. Downloads manifest supplies revisions/paths and past verified-file names, but contains no literal SHA digests; config supplies expected digests. Both are hashed. Safetensors are opened one module at a time; no full model, training, forward evaluation, SVD, GPU computation, downloads or installations occur. Tiny toy tensor operations are validation only.

CSV empty cells mean undefined zero-denominator ratios. All denominator row norms must be positive/finite; failures raise rather than clamp. Only relative surrogate g error uses minimum-positive protection; if g=0 it should be interpreted with recorded m_zero count. Quantiles use NumPy linear interpolation. No p values or independent-training claims are made. Manifest omits its own hash to avoid cycles. Logs and compressed row data remain server-side.

Validation tolerances: the toy energy decomposition uses relative tolerance3e-6 and absolute tolerance1e-10 (first attempt at2e-6 narrowly failed at an observed2.10e-6 FP32 cancellation residual; its server log is preserved as pilot-attempt1.log). Full module Delta decomposition requires relative residual<2e-5. Row norm identities allow absolute error2e-6*max(|m|,n,baseNorm)+2e-7. Explicit FP32 subtraction checks use rtol2e-3/atol2e-7; global group sums use rtol/atol1e-12. The row baseline and BF16 equality counts have exact comparisons.
