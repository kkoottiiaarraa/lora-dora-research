# Память проекта

## Режим работы при анализе — решение пользователя 2026-10-11

Если для анализа нужны графики, таблицы, сравнения, извлечение данных или другая
техническая подготовка, основной агент сначала составляет чёткое ТЗ с входами,
выходами и проверками, затем отдаёт реализацию агенту **gpt-6.1-sol** с уровнем
усилий **low**. Основной агент отвечает за исследовательский замысел и проверку
результата; не расходует высокий уровень рассуждений на техническую реализацию.
Агенту с переопределением модели передавать самодостаточную задачу (fork_turns=none).
До трёх помощников одновременно. Не смешивать техническую подготовку и научную
интерпретацию без явного перехода к анализу.

правила сервера. Последний общий лимит исследования — 6 GPU одновременно.
Разрешение на ресурсы не расширяет исследовательский план: на текущем этапе
подготовки новые модельные прогоны не нужны.
