# Открытые эксперименты LoRA / DoRA для анализа без обучения

Проверено 9 октября 2026 года. Проверка публикаций, файловых каталогов, небольших конфигураций и заголовков safetensors. Полные модели не загружались; инференс и воспроизведение метрик не запускались. Наличие файлов не означает подтверждённую воспроизводимость.

После расширенного поиска обнаружены дополнительные пары и ограничения. Актуальный расширенный список: [CHECKPOINT_INVENTORY_2026-10-09.md](CHECKPOINT_INVENTORY_2026-10-09.md); машинные идентификаторы и версии файлов: [checkpoint_inventory.json](checkpoint_inventory.json).

## 1. Answer.AI: Llama-2-7B, Orca-Math, QLoRA / QDoRA

Наиболее конкретный новый комплект для первого анализа без собственного обучения.

- Публикация: https://www.answer.ai/posts/2024-04-26-fsdp-qdora-llama3.html
- Код: https://github.com/AnswerDotAI/fsdp_qlora
- Скрипт оценки, связанный с публикацией: https://github.com/AnswerDotAI/fsdp_qlora/blob/e454d3180ef575654279d6ac444a86cb0bb3ff33/evaluate.py
- База: https://huggingface.co/meta-llama/Llama-2-7b-hf (доступ регулируется условиями Meta).
- Данные: https://huggingface.co/datasets/microsoft/orca-math-word-problems-200k
- Коллекция: https://huggingface.co/collections/answerdotai/quantized-ft-orca-math-661eafb3db85e1ae77a3ffda
- QLoRA, 10k: https://huggingface.co/answerdotai/llama-7b-orca-math-10k-bnb-qlora
- QDoRA, 10k: https://huggingface.co/answerdotai/llama-7b-orca-math-10k-bnb-qdora
- QLoRA, 100k: https://huggingface.co/answerdotai/llama-7b-orca-math-100k-bnb-qlora
- QDoRA, 100k: https://huggingface.co/answerdotai/llama-7b-orca-math-100k-bnb-qdora
- Есть также полный fine-tuning на 10k / 100k и отдельные выпуски Llama-3-8B.

Опубликованный exact match на 500 примерах для Llama-2-7B: 10k — QLoRA 0.098, QDoRA 0.176; 100k — QLoRA 0.118, QDoRA 0.312. Авторы характеризуют опыт как предварительный, без подбора гиперпараметров.

Файлы 10k проверены через HTTP Range, без загрузки всех весов:

- QLoRA: `model_state_dict.safetensors`, 4,049,181,232 байта, 675 тензоров; содержит A/B ранга 64 и другие веса.
- QDoRA: `model_state_dict.safetensors`, 288,792,992 байта, 576 тензоров; содержит A/B ранга 64 и 192 вектора магнитуды.
- Форматы различаются. Скрипт оценки восстанавливает квантованную базу и загружает соответствующие обученные параметры; нельзя считать эти файлы взаимозаменяемыми стандартными PEFT-адаптерами.
- В просмотренном коде данные перемешиваются с seed 42. Оценка выбирает последние 5000 строк перемешанного набора, затем первые 500 из них.
- Промежуточные состояния и состояния оптимизатора в проверенных выпусках не найдены.

Ограничение: это квантованные варианты. Нужно учитывать ошибку квантования и восстанавливать именно базу, использованную кодом. Результат не переносится автоматически на обычную DoRA.

## 2. Исходная DoRA: LLaVA-1.5-7B

Кандидат для анализа обычных, неквантованных LoRA / DoRA.

- Статья, §5.3: https://arxiv.org/html/2402.09353v6
- DoRA: https://huggingface.co/sliuau/DoRA-weights/tree/main/llava-v1.5-7b-dora-release
- LoRA: https://huggingface.co/liuhaotian/llava-v1.5-7b-lora
- Полный fine-tuning: https://huggingface.co/liuhaotian/llava-v1.5-7b
- Код и данные: https://github.com/NVlabs/DoRA/tree/main/visual_instruction_tuning
- База языка: https://huggingface.co/lmsys/vicuna-7b-v1.5
- База зрения: https://huggingface.co/openai/clip-vit-large-patch14-336
- Исходный проектор: https://huggingface.co/liuhaotian/llava-v1.5-mlp2x-336px-pretrain-vicuna-7b-v1.5
- Аннотации обучения: https://huggingface.co/datasets/liuhaotian/LLaVA-Instruct-150K/blob/main/llava_v1_5_mix665k.json

Проверены обе конфигурации адаптеров: ранг 128, alpha 256, dropout 0.05, одинаковые семь типов проекций. Обе модели указывают Vicuna-7B-v1.5 и одинаковую башню CLIP. Это проверка конфигураций, не доказательство идентичности всех условий обучения.

Есть `adapter_model.bin`, `non_lora_trainables.bin`, `config.json`, `adapter_config.json`, `trainer_state.json`. Адаптеры занимают примерно 640–643 МБ каждый, остальные обученные параметры — примерно 42 МБ. `trainer_state.json` содержит логи, но не промежуточные веса. Финальные шаги: DoRA 5197, LoRA 5198.

Для анализа важно загрузить и остальные обученные параметры, прежде всего мультимодальный проектор. Сырые изображения обучения не нужны для спектрального анализа; для проверки поведения можно начать с одного открытого оценочного набора, а не со всей смеси обучения. Часть исходных тестовых метрик требует серверной оценки.

## 3. Литература о механизме

- **Calibrating and Rotating**, https://arxiv.org/abs/2511.00051 ; код https://github.com/MaeChd/SORA . Диагональное conditioning и энтропия спектра. Готового сопоставимого комплекта LoRA / DoRA для спектральных рисунков в просмотренном выпуске не найдено.
- **DeLoRA**, https://arxiv.org/html/2503.18225v2 ; код https://github.com/ExplainableML/DeLoRA . Приложение C уже сравнивает DoRA с обучаемой и фиксированной магнитудой в небольшом опыте персонализации Stable Diffusion: DINO 0.683 / 0.681, CLIP-I 0.820 / 0.822 соответственно. Это контроль обучения, не удаление магнитуды после обучения. Готовой пары нужных весов не найдено.
- **PoLAR**, https://arxiv.org/abs/2506.03133 ; код https://github.com/kcc-lion/polar . Анализ использования ранга и спектра, включая DoRA. Готовой сопоставимой пары LoRA / DoRA в просмотренном выпуске не найдено.
- **BiDoRA**, https://arxiv.org/abs/2410.09758 ; код https://github.com/t2ance/BiDoRA . Совместная оптимизация магнитуды и направления, переобучение, раздельные уровни оптимизации. Готовой пары нужных весов не найдено.
- **MAP**, https://arxiv.org/abs/2505.23094 . Критика выбора нормирования по столбцам и альтернативное масштабирование. Наличие таблиц сравнения не означает наличие авторских весов всех базовых методов.

## 5. Одна исследовательская гипотеза

Проверить, насколько преимущество готового DoRA-чекпойнта опирается на полезную часть эффективного обновления за пределами ранга обычной LoRA, а насколько высокий ранг / энтропия лишь описывают запись весов.

Без нового обучения можно восстановить эффективные обновления, измерить спектр и локальные изменения выходов на реальных входах, затем сравнить исходную модель с вариантами без диагонального conditioning, с исходными магнитудами при сохранённой обученной направляющей добавке и с низкоранговым приближением эффективного обновления.

Эти вмешательства проверяют роль компонентов конечного решения. Они не доказывают, что другая обученная LoRA не смогла бы добиться того же качества, и не восстанавливают причину траектории оптимизации.
